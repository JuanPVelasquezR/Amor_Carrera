# Física × Biología — Para Luna Rodríguez (Abocito)

Página web interactiva nocturna y pensada primero para celular, desplegable directamente en Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

## Despliegue en Vercel

1. Sube esta carpeta a un repositorio de GitHub (puede ser privado) o ejecuta `npx vercel` dentro de esta carpeta.
2. Vercel detecta automáticamente Vite (`npm run build` → salida en `dist/`).
